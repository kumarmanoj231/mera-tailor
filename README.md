# 🧵 MeraTailor

👔 **MeraTailor** is a platform that connects customers with suitable nearby tailors, making it easier to discover, contact, and manage tailoring services.

## 🚀 How It Works

1. 📍 **Find a Tailor** — Discover suitable tailors near you based on your requirements.
2. 🔎 **Explore Profiles** — View tailor details, specialties, experience, ratings, and services.
3. 📞 **Contact Directly** — Call the tailor to discuss your requirements and get a quote.
4. 📏 **Share Measurements** — Provide your measurements using the available options.
5. 📝 **Place an Order** — Confirm your tailoring requirements and order details.
6. 💳 **Make Payment** — Complete the configured payment securely.
7. 📦 **Track Progress** — Follow the order status until it is ready for collection.
8. ⭐ **Review & Reorder** — Review completed orders and easily repeat an order with a trusted tailor.

## 🛠️ Technology

**MERN Stack**

* 🍃 MongoDB — Database
* 🚂 Express.js — Backend framework
* ⚛️ React — Frontend
* 🟢 Node.js — Runtime environment

## 🎯 Vision

✨ Make finding and working with a trusted tailor simple, accessible, and convenient.
